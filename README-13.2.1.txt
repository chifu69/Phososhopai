PHOTO IA 13.2.1 — QUOTA FIX

Corrección:
- Safari ya no intenta guardar imágenes completas Base64 dentro de localStorage.
- El historial de resultados permanece disponible durante la sesión actual.
- La dirección y el token siguen guardándose cuando Safari tiene espacio.
- Si el almacenamiento está lleno, la generación no se cancela ni pierde el resultado.
- Se limpia automáticamente el historial antiguo que causaba “The quota has been exceeded”.

Instalación:
Reemplaza los archivos de PHOTO IA 13.2 con el contenido de esta carpeta.
Después cierra PHOTO IA por completo y vuelve a abrirla para cargar el nuevo caché.
